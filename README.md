# Official.ENX Runtime Engine

This repository contains `pythonscript.py`, the official and strictly required core engine for parsing, validating, and executing `.enx` files. 

**Without this certified engine, .enx files will not execute.**

## 📥 Installation

To use `.enx` files in your own project, you must download the official engine from this repository. 

1. Download `pythonscript.py` and place it in the root directory of your project.
2. Ensure you have Python 3.x installed on your system.

## 🚀 How to Use

### Command Line Execution
You can run any `.enx` file by passing it through the official engine in your terminal:

```bash
python pythonscript.py your_app.enx
